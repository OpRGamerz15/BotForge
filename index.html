A Bot Directory for Discord

Publish your bot.
Let servers find it.

BotForge is a directory and dashboard for Discord bots — think Modrinth, but for bots. List your bot with a description, invite link, and profile picture. Server admins browse, search, and add bots in one click.

or browse the bot directory without logging in →
🔎
Public Directory
Every registered bot gets a public listing. Search by name, filter by category, sort by popularity.
🔐
OAuth2 Auth
Secure Discord OAuth2 login. Only server owners and admins can add a bot to their own servers.
🤖
Multi-Bot Support
Register as many bots as you like, each with its own page, invite link, and management panel.
⭐
Upvotes
Users can upvote bots they like, helping the best listings surface to the top of Discover.
